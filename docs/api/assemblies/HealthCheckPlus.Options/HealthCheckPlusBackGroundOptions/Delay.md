### HealthCheckPlusBackGroundOptions.Delay property
</br>


#### Gets or sets the initial delay applied after the application starts before executing HealthCheckPlus background service. The delay is applied once at startup, and does not apply to subsequent iterations. The default value is 5 seconds.

```csharp
public TimeSpan Delay { get; set; }
```

### Remarks

The `Delay` cannot be set to a negative value. Unlike the period properties, sub-second and zero values are valid here - this is a one-shot startup delay, not a recurring poll interval.
